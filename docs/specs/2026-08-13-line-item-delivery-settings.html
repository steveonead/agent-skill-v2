Line Item 與投放設定

定義 Campaign 下唯一可投放實體 Line Item 的生命週期、預算、定向、媒體名單、上刊與檢視操作。

Draftzh-TWSeed: #801

Overview

Scope
需求來源

本 draft 僅根據 Issue #801，未讀取相依 issue 或程式碼；所有跨層、API 與資料結構主張均非 verified。

https://github.com/onead/super-dsp-2.0/issues/801

✓Goals
  • 建立、設定與管理單一 Campaign 下的 LI。
  • 以狀態及欄位規則控制可編輯性與上刊。
  • 同頁設定預算日曆、定向及媒體名單。
✕Out of Scope
  • 素材包、追蹤碼與成效計算。
  • EXTERNAL/DSP、再行銷、相似與自訂受眾。
  • 媒體名單自助管理、上刊通報、每日／每週頻次。
  1. 01

    建立草稿

    Campaign 詳情頁以名稱和廣告格式建立 draft。

  2. 02

    暫存設定

    獨立詳情頁分區編輯、頁面層儲存或放棄。

  3. 03

    上刊管理

    Campaign 內列表執行閘門、上刊、暫停和停刊。

建立後導往詳情頁並以頁面層級儲存。未儲存變更不可被離開操作靜默丟失。

預算以整數 NT$ 管理，日曆在走期與總預算有效後出現。總預算改動不會自動重分配每日預算。

Domain Rules

Lifecycle & validation
stateDiagram-v2
  [*] --> draft
  draft --> active: AC-09 上刊通過
  active --> paused: 暫停
  active --> completed: 走期隔日 00:00
  paused --> active: AC-09 重新上刊
  paused --> stop: 確認停刊
  stop --> [*]
  completed --> [*]

LI 狀態機；archived 是獨立旗標，paused 過期不自動完成。

欄位群draftactivepausedstop / completed
名稱可改可改可改唯讀
總預算、走期、日預算、時段、定向可改唯讀，先暫停可改唯讀
品類、格式、計價、節奏、媒體名單可改永久凍結永久凍結唯讀
投放優先層級限 AOE限 AOE，可直接改限 AOE唯讀

上刊閘門摘要

類別必須通過
狀態與歸屬draft/paused、未封存、Campaign 存在且未刪除
走期與預算必要欄位、有效走期、總預算大於零、Campaign 預算池足夠
素材與媒體至少一個開啟素材包；有白名單時，候選網站數大於零
定向年齡性別及裝置各至少一值
規則衝突

「每日預算待分配池為 0」在閘門表中為已廢棄，卻在完成定義仍要求驗證為 0，最終規則待確認。

API Interfaces

Proposed contract
接口草案

Issue 未提供現有 route 或型別。下列 REST 契約只為支援這份流程，非已驗證實作。

POST/campaigns/{campaignId}/line-itemsproposed

建立 draft LI。

Parameters

參數位置型別必填說明
campaignIdpathstring是所屬 Campaign
namebodystring是LI 名稱
adFormatTypeIdbodystring是廣告格式

Response 201

{ "id": "li_123", "status": "draft" }
PUT/line-items/{lineItemId}proposed

以完整暫存內容儲存 LI；日額為零的日期移除設定。

Parameters

參數位置型別必填說明
lineItemIdpathstring是LI ID
dailyBudgetsbodyarray是完整正預算日期集合

Response 200

{ "id": "li_123", "saved": true, "pendingBudget": 24000 }
POST/line-items/{lineItemId}/activateproposed

執行全部上刊閘門，失敗時回傳原因集合。

Parameters

參數位置型別必填說明
lineItemIdpathstring是draft 或 paused LI

Response 422

{ "code": "ACTIVATION_FAILED", "reasons": ["NO_DEVICE"] }
